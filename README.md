# Simple Interest Calculator

## Description

The Simple Interest Calculator is a simple application used to calculate the simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal Amount
- Rate of Interest
- Time Period

## Output

The calculator displays the calculated simple interest.

## Example

If:

- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100
